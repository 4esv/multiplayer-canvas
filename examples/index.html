multiplayer-canvas examples

One page per primitive. Each page imports from multiplayer-canvas/* through an import map.

  • pixel-type + dust: a title as pixels, which a cursor disturbs
  • slime: the slime mould in a dish, click to feed it
  • sky: the weather window, one frame a step
  • kit: tokens, the snap scrollbar, a marquee, an armed button
  • presence: open it in two tabs and move the mouse
